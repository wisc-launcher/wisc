### Added

- Keyboard shortcuts: `Ctrl+1`–`Ctrl+5` switch pages, `Ctrl+F` focuses search,
  `Ctrl+L` opens Logs, `Enter` launches the selected profile, and `Esc` leaves a
  Settings subpage.
- Game Logs has a filter field, an **Errors** toggle, an error counter, and a
  **First error** jump, plus a **Copy Info** diagnostics button in Settings > About.
- Profiles remember and show when they were last played on Home and in the Library.

### Changed

- The launch button uses bundled play/stop artwork instead of platform icons.
- Empty Home and Library states explain what to do and offer a **New profile**
  action.

### Fixed

- Home's launch button shows **Running** while Minecraft is open and no longer
  starts a second game when clicked again.
