### Added

- Discover and download shaders and texture packs from Modrinth or CurseForge using the content selector in Mods.
- Choose a compatible pack version and install it into the selected profile's shaderpacks or resourcepacks folder, with verified downloads and support for manual CurseForge files.
- View installed pack ZIPs, open their folder, and remove packs from the launcher. Shaders include a reminder to use Iris or OptiFine.
- Shader and texture pack lists use the existing Mods card surfaces and row spacing.
