### Added

- Add a built-in 1K FPS Mode that applies a high frame rate preset, ships its own performance mod, and patches the F3 counter to read 1000 fps on every instance version, including Vanilla, Forge, NeoForge, and OptiFine launches.
- Offer to install recommended Fabric performance mods (Sodium, Lithium, FerriteCore, ImmediatelyFast, EntityCulling, ModernFix) the first time 1K FPS Mode launches, with Launcher settings to change the choice later.

### Changed

- Apply the 1K FPS JVM flags and mod only for Fabric and Quilt instances, keeping other loaders on the agent-based path.
