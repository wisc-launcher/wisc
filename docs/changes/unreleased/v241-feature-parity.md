### Added

- Added non-blocking floating toast notifications (`ToastHost`) across the PyQt6 launcher with automatic credential redaction.
- Added an independent `Game Logs` window streaming Minecraft stdout/stderr with color-coded log levels, auto-scroll toggle, copy, and clear actions.
- Added Ely.by sign-in and re-login dialogs with 2FA support in Options > Accounts, syncing account state to Home and Discord Rich Presence.
- Added offline skin/cape upload, Classic/Slim model switching, automatic startup skin cache pruning, and manual Skin Cache pruning in Options > Game.
- Added Game Optimization JVM presets (`Aikar's Flags (G1GC)`, `ZGC`, `Shenandoah GC`), global JVM arguments, and Java Auto-Detect in Options > Java & Memory.
- Added startup and live local `.minecraft` installation sync, pre-launch connectivity and Ely.by token checks, profile Repair, Move Up / Move Down ordering, last-selected profile persistence, and Discord Rich Presence & window restore on game exit.
- Added in-launcher update checks, update review dialog, download progress, restart handoff, What's New release notes dialog, community links, and Reset All Settings in Options > About.
