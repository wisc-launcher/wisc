WISC / GUIDE

Before you hit Play.

A simple launch checklist for Wisc. Check these settings in the launcher and your game folder.

01

Check the Java version

In Options → Java, select a runtime compatible with your exact Minecraft release and loader.

02

Check the selected profile

Confirm the Minecraft version, loader, game folder, and RAM allocation in your profile’s settings.

03

Let the first installation finish

Keep a connection available for missing game files, libraries, assets, and loader downloads. Previously installed files can be used offline.

04

Match your mods

Use mod versions built for your profile’s game version and loader. Install required dependencies and remove duplicate versions.

05

Read the game output

When a launch fails, find the first meaningful error in the captured game output. Share only the relevant, redacted lines when reporting a bug.
