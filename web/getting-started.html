WISC / GUIDE

Your first world awaits.

Install the launcher, choose a profile, and make sure Java matches your Minecraft version.

01 / Get the launcher

Use the Windows installer or portable ZIP. For a portable build, extract the entire archive before running Wisc.exe.

02 / Choose an account

Set an offline username or sign in with an Ely.by account, the account options currently available in Wisc. Server access depends on the server’s authentication rules.

03 / Create a profile

Use the Latest Release shortcut, or open Library → New Profile to choose a Minecraft version and Fabric, Forge, NeoForge, or Quilt. Keep each modded setup in its own instance.

04 / Set Java and play

In Options → Java, choose a compatible Java executable and a sensible RAM allocation. Keep an internet connection for the first installation. Once all required files are installed, offline launches are possible.

Java requirements vary by Minecraft release. Minecraft 1.20.5 and 1.21 commonly use Java 21, 1.18–1.20.4 use Java 17, and many older versions use Java 8. Check your exact game and loader requirements.

Run from source

Install Git, Python 3.10+, and Java. On Linux or macOS:

git clone https://github.com/wisc-launcher/wisc.git
cd wisc
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py

On Windows PowerShell:

py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
