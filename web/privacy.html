WISC / GUIDE

Your data, explained.

Understand the website’s external requests and the launcher’s local data and connected services.

This website

There is no website sign-in, checkout, added analytics, advertising, or local-storage feature. Fonts are served from this website’s own assets. The hosting provider processes requests to deliver the pages. Opening a GitHub link sends a request to GitHub.

The website’s release API requests public release information from the project’s GitHub repository. It does not need your account or launcher credentials.

Your launcher data

The desktop launcher stores settings, profiles, and cached skins locally. Ely.by sessions use native credential storage when available, with a memory-only fallback. The launcher redacts credentials from displayed or exported game logs. Review logs and screenshots before sharing them.

Game downloads, account sign-in, skin refresh, and mod searches contact the services used by those features. Optional Discord Rich Presence shares launcher or game activity with Discord when enabled.

Service policies

External services apply their own policies, including Vercel and GitHub. Use the project’s public issue tracker for project questions, without posting private information.
