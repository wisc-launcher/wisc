WISC / MODS

Your mods, in order.

Discover compatible mods, install local JARs, and manage each profile’s collection.

Start with the right profile

Open Mods and select the profile you want to change. Match the Minecraft version and loader before installing. Fabric, Forge, NeoForge, and Quilt mods have different compatibility requirements.

Discover a mod

Search Modrinth or CurseForge, open project details, and choose a compatible version. CurseForge requires a launcher API key through its provider setup button.

Browse Modrinth ↗

Bring your own JAR

Use the launcher’s local installation action or open the profile’s game folder and place compatible JARs in its mods directory.

Read guide →

Update thoughtfully

Check updates for ordinary installed mods. Pack-managed files keep their pinned versions; install another pack version as a separate instance.

Read guide →

Enable, disable, undo

Disable mods while investigating a conflict, or remove a mod and use the launcher’s Undo notification when available. Back up worlds before changing a modded setup.

The launcher displays download progress and verification errors. Some CurseForge files require manual download from the official file link.
