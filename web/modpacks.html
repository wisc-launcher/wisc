WISC / MODPACKS

A whole new setup.

Browse Modrinth and CurseForge packs, or import a pack archive into a separate instance.

Discover → Review → Install

Open Mods → Content type → Modpacks. Search a provider, open a pack, and choose a release. Review its Minecraft version, loader, instance folder, downloads, and optional files before confirming. Every installation creates a separate instance.

Downloads are verified before the pack appears in Library. Canceled or failed installations preserve existing instances.

Import a pack

Import a Modrinth .mrpack or a CurseForge export ZIP with a root manifest.json. Other launcher instance ZIP formats are not supported. CurseForge may need its provider API key to resolve referenced files. Some files require a manual download from their official link.

Keep the pack’s pins

Pack-owned JARs show Pack managed. Normal mod updates retain their pinned versions. Install another pack release as a new instance to keep your existing worlds and customizations. Updating a pack in place is not currently supported.
